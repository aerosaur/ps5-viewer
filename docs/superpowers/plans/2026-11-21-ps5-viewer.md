# PS5 Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small Windows desktop app (Tauri 2) that shows a PS5 through an Elgato Cam Link 4K with no added buffering. It looks like mockup E and has its own volume control, separate from Windows.

**Architecture:** A plain HTML/CSS/ES-module frontend in `src/`, with no framework and no bundler. Pure logic lives in `src/lib/` and is unit-tested with `node --test`. Browser-API code lives in `src/capture/` and `src/ui/`. Everything Tauri-specific goes through `src/platform.js`, which falls back to no-ops in a plain browser so the UI can be iterated in Chrome on the Mac. The Rust side in `src-tauri/` stays minimal: config, global-shortcut plugin, auto-granting WebView2 permissions, and turning off background throttling. GitHub Actions on `windows-latest` builds the `.exe`.

**Tech Stack:** Tauri 2 (`@tauri-apps/cli` 2.12.x, `tauri` 2.x crate), `tauri-plugin-global-shortcut` 2.x, `webview2-com` (Windows only), Node 24 built-in test runner, `tauri-apps/tauri-action@v0`.

**Spec:** `docs/superpowers/specs/2026-11-21-ps5-viewer-design.md` · **Visual reference:** `docs/design/mockup-E.dc.html`

## Global Constraints

- **Target:** Windows 10/11 x64, using WebView2 (preinstalled). Built **only** in CI. The Mac has no Rust toolchain, so Rust compiles are checked by CI runs (`gh run watch`).
- **Repo:** private `aerosaur/ps5-viewer`. Never commit tokens.
- **Capture:** device label contains `Cam Link` (fall back to the first device of that kind). Video `1920×1080 @ 60`. Audio with `echoCancellation:false, noiseSuppression:false, autoGainControl:false, channelCount:2, sampleRate:48000`. `AudioContext({latencyHint:'interactive'})`.
- **Volume:** 0–100. Keys and arrows step by 5, scroll steps by 1. Gain is `(v/100)²`. The display shows `String(v).padStart(3,'0')`, or `MUTE`.
- **Window:** frameless (`decorations:false`), default 1040×790, title `PS5`. Mini is 480×270, always on top, at the bottom-right of the current monitor.
- **Local keys:** `ArrowUp`/`ArrowDown` ±5, `m` mute, `h` hide, `n` mini, `f` fullscreen, `d` diagnostics, `Escape` leaves full/mini.
- **Global keys:** `CommandOrControl+Alt+Up`, `CommandOrControl+Alt+Down`, `CommandOrControl+Alt+M`. If one fails to register, skip it silently.
- **Persisted in localStorage** under key `ps5viewer:v1`: `{volume, muted, controlsHidden, bounds}`. Defaults are `{volume:60, muted:false, controlsHidden:false, bounds:null}`.
- **Picture states (exact copy):** `NO DEVICE` · `NO SIGNAL` with hint `CHECK PS5 IS ON · HDCP OFF` · `DEVICE IN USE` with hint `CLOSE OBS OR OTHER CAPTURE APPS`. Retry every 2000 ms. No-signal is declared after 3000 ms without frames, or with only black frames.
- **Look:** every colour, size and copy string comes from `docs/design/mockup-E.dc.html`. Font is IBM Plex Mono, **bundled locally** (woff2 in `src/fonts/`) with no network font loading.
- **No dependencies in `src/`**: no npm runtime packages, no CDN.

## Review Focus

1. **Cam Link unplugged and replugged mid-session:** it should go to `NO DEVICE` and then recover on its own without restarting. Pinned by the `devicechange`/retry test in Task 2 (`signal.test.js`) and the manual check in Task 4.
2. **Display scaling at 125%/150%:** hide and mini sizes must come out right, not tiny or huge. Pinned by the scale-factor cases in Task 2 (`geometry.test.js`).
3. **Saved window position off-screen** (a second monitor removed, or resolution changed): the window must land on a visible monitor. Pinned by the `clampToMonitor` test in Task 2.
4. **Corrupt or old localStorage:** fall back to defaults and don't crash. Pinned by the `state.test.js` corrupt-JSON and out-of-range cases in Task 2.
5. **A global shortcut is already taken** by another app: the others still register and nothing errors. Pinned by the `registerShortcuts` test in Task 5 (`platform.test.js`).
